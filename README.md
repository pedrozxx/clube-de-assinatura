# Clube de Assinatura

Landing page de um clube de assinatura de livros, construída para praticar **animações e transições em CSS**: revelação de elementos ao rolar a página, movimento nos cards de mistério e microinterações nos botões.

🔗 **[Abrir o projeto](https://pedrozxx.github.io/clube-de-assinatura/)**

## O que este projeto exercita

- Animações com `@keyframes`, `transition` e `transform`.
- Composição de seções: hero, planos, mistérios do mês e rodapé.
- Organização do CSS em arquivos por responsabilidade (`hero`, `header`, `button`, `animation`).
- Layout responsivo.

## Tecnologias

HTML5 · CSS3 (sem dependências ou build)

## Como executar

```bash
git clone https://github.com/pedrozxx/clube-de-assinatura.git
cd clube-de-assinatura
```

Abra o `index.html` no navegador.

## Estrutura

```
index.html              marcação da página
styles/
  global.css            reset, variáveis e tipografia
  header.css            cabeçalho e navegação
  hero.css              seção de abertura
  button.css            botões e estados
  animation.css         animações de entrada
  animation-books.css   movimento dos livros
assets/                 imagens, ícones e logos
```
